# Third-party notices

Nerx UI is an independent interface library. It is not affiliated with or
endorsed by Neverlose.

## Design inspiration

The component language and visual direction are inspired by the Neverlose
Lua interface (pills, slider rails, dark fields, indicators, popups). No
official Neverlose source repository is vendored here.

## Icon glyphs

Interface glyphs use Roblox's built-in **BuilderIcons** font:

```
rbxasset://LuaPackages/Packages/_Index/BuilderIcons/BuilderIcons/BuilderIcons.json
```

BuilderIcons is a Roblox client asset and is not redistributed by this
repository.

## Neverlose brand marks

`assets/neverlose-mark.png` and `assets/neverlose-mark-alt.png` come from:

<https://github.com/tickcount/.p2c-icons>

That repository is MIT licensed. A copy of its license is included at
`assets/p2c-icons-LICENSE.txt`.

The marks are optional and are only used when the consumer explicitly passes
`Logo = Nerx:GetNeverloseLogo()` or another image asset.
